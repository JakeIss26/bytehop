# ByteHop

ByteHop is a cross-platform peer-to-peer file transfer application built with Java.

Its goal is to provide fast, reliable, and secure file transfers between devices without relying on cloud storage or external servers.

## Planned Features

- Direct file transfer over a local network
- Automatic device discovery
- Concurrent file transfers
- Asynchronous network operations
- Real-time transfer progress
- File integrity verification
- Secure communication
- Interactive terminal interface

## Tech Stack

- Java
- Maven
- Java Networking API
- Java Concurrency API

## Project Status

Early development — not ready for production use.
